审查日期：2026-07-21

## 范围与结论

前端是 Vue 3 + Vite 的单页聊天原型，入口为 `src/main.ts`，`App.vue` 仅承载路由视图，根路由与 `/chat`、`/ai-chat`、`/app` 别名都指向 `views/AiChat.vue`。没有浏览器扩展、Pinia、独立状态层、组件拆分、测试或 Mock Server。

依赖声明为 Vue `^3.4.21`（锁定 `3.5.40`）、Vite `^5.0.12`（锁定 `5.4.21`）、TypeScript `5.4.5`、vue-router `^4.3.0`（锁定 `4.6.4`）、Element Plus 与 Axios；锁文件为 npm `package-lock.json` v3。脚本仅有 `dev`、`typecheck`、`build` 与 `preview`。

`src/api/client.ts` 用 Axios 创建了唯一客户端，默认基址为 `/api`、超时 15 秒；`VITE_API_BASE_URL` 和 `VITE_PROXY_TARGET` 均有示例配置。Vite 开发代理将 `/api` 转发到 `http://127.0.0.1:8000`（可由 `VITE_PROXY_TARGET` 覆盖）。

`AiChat.vue` 在页面内保存消息、输入、加载、服务状态和模型配置；它直接调用旧接口 `/status`、`/questions/recommended`、`/config/model` 与 `/chat`。网络错误由组件内 `errorMessage` 处理，503 时刷新状态；回答以文本和 `sources`（文件、页码、距离、预览）展示。没有复制按钮、反馈、风险/转人工、契约错误映射或取消请求。

## 实际页面链路

```text
文本输入或推荐问题
→ AiChat.vue 的 inputMessage / messages / loading
→ Axios client（/api，15 秒超时）
→ POST /chat { message }
→ answer + sources
→ 回答气泡与来源预览
→ 当前无复制功能
```

## 与共享契约的差异

共享契约版本为 `0.1.0`。`assistant-request.schema.json` 要求 tenant、平台、店铺、会话、客户消息和 client_mode；旧页面只发送 `message`。`assistant-response.schema.json` 要求 request_id、action、risk_level、citations、warnings、required_fields 和 latency_ms；旧页面只消费 answer 与 sources。因此旧 API 调用只能作为历史基线，不能视为契约兼容实现。

## 已冻结的技术债

2. API 客户端、错误映射和页面状态耦合在单页内；没有 `ragClient`、`platformClient`、`errorMapper` 或 Pinia。
