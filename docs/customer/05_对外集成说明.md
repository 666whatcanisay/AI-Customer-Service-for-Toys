# 对外集成说明

B 线只通过公开 HTTP API 与 A/C 集成，不读取对方数据库、向量库或内部模块。

- A：`VITE_RAG_API_BASE_URL`，使用 `GET /api/health`、`POST /api/chat`。
- C：`VITE_PLATFORM_API_BASE_URL`，使用 `GET /health`、`GET /api/v1/test-catalog/stores`、`GET /api/v1/test-catalog/products?store_code=`、`GET /api/v1/test-catalog/products/{product_id}/skus`。
- 字段差异只允许在 `ragAdapter.ts`、`platformAdapter.ts` 中处理，页面不拼装兼容字段。
- 生产运行不回退 Mock；组件测试 Mock 有明确 Vitest 边界。
- A/C 错误和超时分开提示，不用其中一个服务的成功掩盖另一个失败。
- A 未发布反馈端点，采用结果仍只在页面记录，不声称远端持久化。
- 固定试用边界：`test_data_mode=true`、`production_usable=false`、`response_mode=SUGGESTION_ONLY`、`allow_auto_send=false`。

当前 A/C 均未提供可完成 B-T03 的联调组合，真实页面 smoke 为 `INTEGRATION_PENDING`。

B-T03-FIX1 只消费上述三个冻结目录路径，不保留旧路径或生产回退。
