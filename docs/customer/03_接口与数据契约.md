# 接口与数据契约

共享基础契约版本为 0.1.0，位置为共享仓库 contracts/；B-T02 没有修改公共契约。

当前实际集成接口为 `GET /api/health` 和 `POST /api/chat`，聊天请求为 `{ "message": string }`。总控同步的 A 线目标响应为 `answer/action/sources/model/latency_ms/request_id`，source 为 `source_name/page/chunk_id/distance/excerpt`，action 当前为 `ANSWER` 或 `REFUSE`，risk 尚未实现。

B 线在 `ragAdapter.ts` 中集中执行兼容：`ANSWER` 映射为 `DIRECT_ANSWER`；目标 citation 字段与运行实例的 `file/content_preview` 等遗留字段归一化；缺失 action/risk 保持未分类，不在页面猜测。共享 `assistant-request/response` 与当前 A 接口的差异记录在 `12_B-T02_真实RAG_API集成报告.md`，后续破坏性变更仍须通过跨线契约提案。
