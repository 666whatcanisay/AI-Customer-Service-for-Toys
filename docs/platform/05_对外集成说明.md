# 对外集成说明

只通过版本化 API/JSON Schema 集成。不得把其他平台特例或内部数据访问耦合到本线。

C-T02B 提供五个 C 线权威只读接口，固定测试上下文为 `TENANT-PDD-SM-TEST/pdd/PDD-SM`。响应字段与数组类型见 `data-ingestion/12_C-T02B测试数据包.md`；错误继续使用现有统一信封。接口永远返回 `test_data_mode=true`、`production_usable=false`、`response_mode=SUGGESTION_ONLY`、`allow_auto_send=false`。

本轮兼容约定只在任务文档与 C 线 schema/test 中冻结，未修改 `contracts/**`。A/B 可在后续获授权任务中消费，但当前未执行跨线真实联调。不得返回附件二进制或原始 RTF，也不得把 C 线内部数据库表当作跨线契约。

## CORS 测试环境约定

C 服务固定监听 `127.0.0.1:8011`。浏览器来源通过 `CORS_ALLOWED_ORIGINS` 配置，默认只允许 `http://127.0.0.1:5173`。多来源使用英文逗号分隔，例如 `http://127.0.0.1:5173,http://localhost:5173`；`localhost` 不会被隐式放行。

服务拒绝空列表、`*`、非 HTTP(S)、携带用户信息、路径、查询或片段的值。当前允许跨域 GET/POST，请求头限于 `Accept`、`Content-Type`、`X-Request-ID`，并向浏览器暴露 `X-Request-ID`。未启用跨域凭据。该配置不代替身份认证或权限控制。
