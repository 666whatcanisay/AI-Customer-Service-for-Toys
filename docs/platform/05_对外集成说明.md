# External integration notes

C-T05 preserves the existing C-owned frozen test-catalog APIs and introduces only C-local administration APIs. `admin_web` calls C through `/platform-api`, proxied in development to `http://127.0.0.1:8011`.

The AI capability center is an availability adapter, not a new integration contract. It probes `/ai-api/api/admin/ai/modules`, proxied to `http://127.0.0.1:8000`. This repository baseline has no matching A-line endpoint/schema. The UI therefore shows “AI service unavailable or interface not merged”, does not call guessed detail/test routes, and does not create module or test-result mock data.

No Kingdee, marketplace, payment, order, source-file, RAG publication, or production-data connection is made by C-T05.
