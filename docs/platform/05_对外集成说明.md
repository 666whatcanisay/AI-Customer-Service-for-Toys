# External integration notes

`admin_web` calls C through `/platform-api`, proxied in development to `http://127.0.0.1:8011`. Existing C-T05 catalog and suggestion paths remain C-owned.

## MVP-PLUS-01 controlled data exchange

The experience-case paths in the frozen MVP-PLUS-01 interface add B submission/status projection and A snapshot/evidence exchange through C. B never receives review notes or A evidence. A receives only C-approved snapshots and returns structured evidence only when its export revision and content hash match. Neither path accesses the C database directly.

The C admin web calls only C-owned internal review/pool endpoints. It intentionally contains no operation to modify a Prompt, publish knowledge, train a model, send a customer message, update an order, or write an ERP record.

The prior AI capability center remains an availability adapter only: it probes `/ai-api/api/admin/ai/modules` through `http://127.0.0.1:8000` and does not infer guessed A-line detail/test paths or fabricate module data.
