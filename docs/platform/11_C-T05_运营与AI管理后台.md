# C-T05 operations and AI management portal baseline

## Scope

The internal-test administration portal makes C-owned imported data observable and actionable without turning it into a publishing system. It contains real counts, catalog/governance/source/conflict views, import links, and a persisted customer-suggestion workflow.

## Data and safety boundary

All business-data pages are read-only. Suggestions are the sole write workflow; only their lifecycle status and `internal_note` can be changed by the administration API. Descriptions are stored in the local database and not logged by this module. The UI masks reporter identity and never turns a suggestion into a knowledge item or a development task automatically.

Only safe source metadata is returned. No attachment download, image preview, raw RTF, raw metadata, local absolute path, production package, formal publication, or automatic message sending is added.

## AI integration boundary

The task-declared module probe uses `/ai-api/api/admin/ai/modules`. It is intentionally tolerant of a currently absent A service, but does not fabricate modules or results. Module detail and online test are visibly unavailable until A supplies a versioned schema and an approved cross-line compatibility review.

## Rollback

Downgrade Alembic revision `0003_ct05_customer_suggestions` to remove only the suggestion table and indexes. The remaining read-only APIs/UI are application code and can be rolled back by reverting the C-T05 commit; existing C-T01–C-PACKAGE-FIX2 tables and interfaces are unaffected.
