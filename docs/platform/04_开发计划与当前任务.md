# Development plan and current task

Current task: C-OPERATION-CENTER-V2-PRODUCTIZATION, the Chinese AI customer-service operations center productization layer for the existing test-only C platform.

Current scope:

- Chinese business navigation: 首页、客服运营、商品知识、AI 管理和系统, while existing direct routes stay compatible.
- Real-source home cards for service, AI usage, cases, questions, knowledge, and pending work; a true empty source is shown as `待启用` or `样本不足`, never as a fabricated trend.
- C-internal global SKU inventory at `GET /api/v1/admin/skus`, backed by existing test catalog data only.
- Chinese state labels and API failure/permission/conflict guidance, including removal of empty query parameters before strict enum requests.
- Browser verification against the current local 5174 build, direct URL refresh, 1366×768 layout, backend API tests, and Admin build paths.

Out of scope: B/A frozen path changes, `contracts/**`, automatic redaction, formal identity/authentication, production authorization, retention/deletion/recovery, knowledge publication, prompt editing, model training, customer messaging, order writes, ERP writes, and automatic business action.

Completed for this task:

- C-owned `AIResponseFeedback` persistence with revision `1`, manual-confirmation freeze, and canonical `sha256:` content hash.
- B create/history with a required server-side `Idempotency-Key` receipt and a minimum personal status projection.
- Read-only `/badcases` export of the complete confirmed frozen snapshot and evidence-only writeback checked against revision, hash, and feedback type.
- Idempotent retry for identical B submission and A analysis payloads; no Admin UI or automatic action.

Previously completed MVP-PLUS-01 C-owned scope:

- An independent `CustomerExperienceCase` revision record with C-owned review/governance fields.
- Human review transitions and immutable `APPROVED` export snapshots.
- Controlled B submission/status projection, controlled A snapshot export/evidence writeback, and C-only review/pool endpoints.
- Experience-library filters/detail/actions and an AI optimization pool that is evidence-only.
- Alembic migration, API tests, admin view tests, typecheck, Vitest, and production-build verification.

This task does not modify B frontend code or Admin UI. It converges the frozen C Provider interface through C-owned B create/history, `/badcases` export, revision/hash/type evidence checks, and idempotent result storage without changing `contracts/**`.

Out of scope: formal roles/login, automatic redaction, product publishing/editing, knowledge publishing, prompt editing/publishing/rollback, automatic training, Kingdee or marketplace APIs, payment/order writes, automated refunds/resends, customer-message sending, A/B business changes, and shared-contract changes.
