# Interfaces and data contracts

Shared contract version remains `contracts/version.json 0.1.0`. C-T05 does not modify `contracts/**`, A/B business code, shared schemas, shared error-code registry, or API contract version.

## C-line local administration APIs

The following C-owned APIs use the existing error envelope `{error:{code,message,details?},request_id}` and bounded `page`/`size` pagination where applicable:

- `POST /api/v1/customer-suggestions` creates a suggestion with forced `SUBMITTED` status.
- `GET /api/v1/customer-suggestions?reporter_id=` lists only the reporter projection and excludes `internal_note`.
- `GET /api/v1/admin/customer-suggestions` filters by lifecycle, module, store, urgency, and keyword.
- `PATCH /api/v1/admin/customer-suggestions/{id}` accepts only `status` and `internal_note`. Invalid lifecycle edges return `SUGGESTION_INVALID_STATUS_TRANSITION` with HTTP 409.
- `GET /api/v1/admin/overview`, `/stores`, `/products`, `/products/{id}`, `/products/{id}/skus`, `/faqs`, `/safety-rules`, `/sources`, `/conflicts`, and `/import-batches` are read-only projections of C-line tables.

Suggestion lifecycle: `SUBMITTED → REVIEWING|PLANNED|REJECTED`; `REVIEWING → PLANNED|DONE|REJECTED`; `PLANNED → DONE|REJECTED`; `DONE` and `REJECTED` are terminal. Input has length limits; descriptions are not logged by the module.

Source responses expose source ID, type, filename, hash, safe relative path/locator, and linked product/SKU IDs only. They suppress absolute paths, raw attachment bytes, raw RTF, and raw metadata.

## Cross-line compatibility note

Affected line: A (AI administration API consumer). The task declares only the read-only probe path `/ai-api/api/admin/ai/modules`, proxied by `admin_web` to `http://127.0.0.1:8000`. No A-line implementation or versioned detail/test schema is present in this baseline. C-T05 therefore adds no field, error-code, or contract-version dependency beyond that path; it makes no detail/test request and renders no mock fallback. A future cross-line change must supply schema, version, changelog, compatibility notes, and affected-line review before enabling those controls.
