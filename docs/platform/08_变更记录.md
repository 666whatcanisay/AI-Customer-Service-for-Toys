# Change log

## 2026-07-25 — MVP-PLUS-02 pilot operations observation dashboard

- Added a C-owned, read-only pilot dashboard API over existing experience cases and an admin-web dashboard showing today's case-observed proxy metrics, case status counts, and exact-question frequency.
- The API/UI state `TEST_OR_PILOT`, `official_operation_report=false`, and `CASE_AI_ANSWER_PROXY`; no production telemetry, complex analytics, writes, or automatic action was added.
- The stacked implementation depends on MVP-PLUS-01's experience-case persistence and does not modify `contracts/**`, A/B business code, or database schema.
- Verified with 68 backend pytest tests, an isolated migration round trip to `0004_mvp_plus_01_experience_cases`, 28 admin-web Vitest tests, and a production build/typecheck.

## 2026-07-25 — MVP-PLUS-01 customer experience case center

- Added C-owned `CustomerExperienceCase`, immutable approval snapshot, and append-only evaluation-evidence persistence in Alembic revision `0004_mvp_plus_01_experience_cases`.
- Implemented the frozen B submission/status-projection and A export/evaluation-result paths, plus C-only review/detail and AI-pool endpoints. Approved revisions generate a content hash and cannot be overwritten.
- Added internal-test Experience Cases and AI Optimization Pool views. They provide filters, detail, human review and evidence display; they do not expose automatic AI, publication, order, or ERP operations.
- `contracts/**` remains `0.1.0`; existing C interfaces are unchanged. Affected future consumers are B for submission/status projection and A for controlled export/evidence only.
- Delivered on `agent/platform-mvp-plus-01` as Draft PR #30 against `develop` after migration/API/admin verification.

## 2026-07-25 — C-T05 B suggestion compatibility

- Added the C-owned, additive response field `suggestion_id` to customer-suggestion POST responses and reporter-history GET items. It is a computed alias of the retained `id` field, so no database migration, lifecycle, error, or shared-contract version change is required.
- An isolated C-to-B smoke verified B's adapter submitted and listed one record while C returned equal `id` and `suggestion_id` values.
