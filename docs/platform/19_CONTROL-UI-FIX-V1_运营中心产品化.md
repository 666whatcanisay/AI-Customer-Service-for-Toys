# CONTROL-UI-FIX-V1：运营中心产品化 UI

## 目标与范围

本轮仅优化 `admin_web/**` 的呈现层，使 5174 的内部测试管理端更接近日常运营软件。它不改变平台数据模型、迁移、生命周期、A/B/C 共享接口、自动化边界或网络配置。

## 冻结术语

| 产品术语 | 对应页面 / 含义 |
| --- | --- |
| AI 运营中心 | 5174 管理端的整体名称；展示运营资料与待处理事项。 |
| AI 控制中心 | A 服务的只读状态、知识、模块、提示词元数据和历史评测入口。 |
| AI 问题与分析 | 已完成回写的 AIResponseFeedback 分析证据；不包含未确认或未分析反馈。 |
| 优化建议 | 已记录的评测或分析建议，供人工判断，不触发 Prompt、知识或业务动作。 |
| 商品资料导入 | 只支持固定 Excel 模板的商品与 SKU 预检/导入流程。 |
| 测试数据包 | 只接受已验证的原始 V0.3.1 ZIP，不提供自行拼装的模板或解压目录入口。 |

## 只读接口复用

AI 控制中心仅消费现有 A 接口，前端 adapter 只把字段转换为中文显示，不新增请求字段或响应字段：

- `GET /api/status`：运行就绪和模型配置。
- `GET /api/knowledge/statistics`：当前集合、知识块和主知识库文档统计。
- `GET /api/admin/ai/modules` 与 `GET /api/admin/ai/modules/{module_id}`：模块及其模型、知识量、安全预览和声明能力。
- `GET /api/admin/ai/modules/{module_id}/prompt`：提示词元数据；绝不读取或展示完整 Prompt。
- `GET /api/admin/ai/modules/{module_id}/evaluations/latest`：历史评测摘要。

当历史评测返回 `passed_cases < total_cases` 时，页面必须明确显示“尚未达到全量通过”。例如 `19/28` 不是通过结论。`document_count=0` 和进程生命周期指标均按接口原意展示，不能伪装成历史趋势、采用率或质量评分。

## 交互与安全边界

- 概览、AI 控制中心、优秀案例评测和 AI 问题与分析优先展示人工可读摘要；模型、Prompt 版本、哈希、运行 ID 和原始 JSON 收在折叠技术区。
- 接口请求失败时显示错误状态；空数据只显示空状态，不创建 Mock 数据或“全绿”结果。
- 未知路由显示中文“页面不存在”，而不是空白壳。
- 数据导入先下载真实 Excel 模板、填写可核对事实、预检后导入；测试数据包明确没有模板下载，先预检原始 ZIP，再导入测试租户。
- 不新增自动发送、订单/ERP 写入、退款、知识发布、模型训练、Prompt 修改或自动评测动作。

## 验收关注点

1. 已声明路由与未知路由均有明确中文页面。
2. AI 服务、集合、模型、提示词元数据、历史评测均来自真实接口；部分失败不能被伪装为空或成功。
3. 客服经验评测与 AI 问题分析名称互不混淆，状态采用既有枚举的中文映射。
4. 导入预检能说明识别结果和失败原因；页面不承诺不存在的文件格式或模板。
