# C-ADMIN-UI-PRODUCTIZATION-V1 说明

## 定位

5174 是内部测试 / 试运行场景中的“AI 客服平台 · 运营管理中心”。本轮只改 C 线的运营呈现和商品资料预检说明，不改变 A、B 或共享契约，也不新增自动业务动作。

## 导航与中文呈现

- 主导航改为左侧单列分组：客服运营、商品知识、AI 管理、系统与弱化的规划功能。
- 规划功能只显示“规划中”，没有可执行入口，不与已交付能力竞争视觉层级。
- 运营状态、测试包状态、错误和空状态以中文业务说明显示；接口枚举仍保留在传输层。

## AI 控制中心

`/ai-control-center` 组合既有 C 健康检查、C 运营聚合、A 能力目录、已回写评测和已完成 AI 问题分析。

- 第一层：AI 是否可用、模型元数据、知识状态、最近评测与最近问题分析。
- 第二层：面向老板、运营和技术负责人的使用说明。
- 第三层：默认收起的技术详情。

能力目录接口可以访问但没有模块时，页面显示“接口可用，暂无可展示数据”，不把接口状态误写成模型质量或生产可用性。

## 分析证据展示

AI 问题、改进建议和评测中心优先显示已有证据中的问题概述、AI 与人工差异、风险判断和建议动作。若字段缺失，使用“未提供”或“暂无建议动作”，不从 JSON 推测结论。原始分析 JSON 仅在用户主动展开“技术详情”后显示。

这些页面仍为只读：没有提示词修改、知识发布、模型训练或业务自动执行入口。

## 数据包与商品导入

测试数据包页提供以下可下载的最小填写模板：

- 商品与 SKU：后端受控的 `.xlsx` 模板；
- FAQ：`.csv` 填写模板；
- 安全规则：`.csv` 填写模板；
- 来源证据：`.csv` 填写模板；
- 测试数据包使用说明：`.md` 下载说明。

后三类 CSV 是填写与预检准备材料，不是导入接口，不能自动上传原始资料、发布知识、训练模型、修改提示词、发送客户消息或写入 ERP。

商品与 SKU 预检在原有无写入校验基础上增加以下 C 内部响应字段：

- `recognized_product_count`：根据商品编码或平台商品 ID 识别到的去重商品数；
- `recognized_sku_count`：根据 SKU 编码或平台 SKU ID 识别到的去重 SKU 数；
- `rows_needing_manual_completion`：非有效状态行数；
- `missing_field_counts`：必填字段缺失行数。

这些字段仅用于当前 C 的导入向导展示；不变更共享 `contracts/**`，不引入跨线接口依赖。

## 数据与安全边界

- 当前仅使用测试 / 试运行数据，不构成正式运营报表。
- 不新增正式身份认证、正式授权、留存、删除、恢复审计或自动脱敏声明。
- 不向首页、日志或导出扩散客服原文；已有受控详情仍沿用试运行管理员 / 运营员读取边界。
