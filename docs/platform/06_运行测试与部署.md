# Local run, test, and deployment notes

The C service listens locally on `127.0.0.1:8011`. Configure `CORS_ALLOWED_ORIGINS=http://127.0.0.1:5173` for the local admin origin; add any additional origin explicitly and never use `*`.

```powershell
cd platform_backend
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m pytest -q
```

For the admin web, use the locked dependencies and bundled Node runtime:

```powershell
cd admin_web
pnpm typecheck
pnpm test
pnpm build
```
