## C-T04 验证（2026-07-23）

固定测试配置：`CORS_ALLOWED_ORIGINS=http://127.0.0.1:5173`，C 端口 8011。应用不会自动读取 `.env`；测试或 OPS 启动器必须设置进程环境变量。

执行命令：

```powershell
cd platform_backend
.\.venv\Scripts\python.exe -m pytest -q
$env:CORS_ALLOWED_ORIGINS = "http://127.0.0.1:5173"
$env:DATABASE_URL = "sqlite:///C:/Users/EDY/AppData/Local/Temp/c-t04-live.sqlite3"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8011 --no-access-log
```
