# AI 客服运营中心 V2 说明

## 定位

5174 是 C 线的内部测试 / 试运行运营中心，不是正式运营报表或生产权限系统。首页只显示已有 C 接口的真实状态与聚合数量；没有来源时使用“待启用”或“样本不足”，不推断趋势。

## 运营首屏

- 老板：平台服务、AI 服务、今日 AI 使用、案例、问题与知识状态。
- 运营：待审核案例、待分析 AI 问题、开放知识冲突，以及店铺到商品/知识维护的下一步入口。
- 技术负责人：系统服务状态、请求编号和折叠后的技术元数据；业务默认页面不以技术字段为主。

## 中文业务导航

- 首页：运营总览。
- 客服运营：客服案例、AI 问题中心、效率分析。
- 商品知识：店铺、商品、SKU、FAQ、安全规则。
- AI 管理：AI 效果、AI 评测、优化建议。
- 系统：服务状态、数据同步、试运行治理。

旧的 C 内部直达路径仍可访问；导航不改变 B/A 冻结接口或 `contracts/**`。

## 数据与错误边界

- `GET /api/v1/admin/operations/today`：内容无关的日运营聚合。
- `GET /health`：C 平台服务状态。
- A 能力目录：只在真实响应成功时显示“AI 可用”；无模块时显示“待启用”。
- `GET /api/v1/admin/skus`：既有测试目录的只读 SKU 清单，可按店铺、商品、关联关系或关键词筛选。
- 前端不会发送空的严格枚举筛选参数；422、越权、未找到和冲突会转换为中文原因与下一步提示。

## 未宣称的能力

本轮没有增加正式身份认证、生产授权、自动脱敏、留存/删除、自动提示词修改、知识发布、模型训练、客户消息、订单或 ERP 写入。固定试运行角色仅用于内部边界验证。
