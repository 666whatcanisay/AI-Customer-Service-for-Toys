# 数据接入与标准化模块

C-T02 建立 C 线内部的商品与 SKU 人工 Excel 接入边界：

```text
固定 XLSX 模板
→ 内存解析
→ 确定性标准化
→ 字段校验
→ 批次内去重/冲突标记
→ 行级错误报告
→ StagedProductSku(PENDING_REVIEW)
```

职责按 `api → service → parser/normalizer/validator → repository` 分离。`ImportBatch` 记录批次，`ImportRow` 隔离原始值、标准值和校验问题，只有 `VALID` 行才能写入 `StagedProductSku`。

本模块不是正式商品主数据系统，也不是知识发布系统。它不调用 A 线、Embedding、Chroma、模型、金蝶或电商平台接口；不修改 `backend/**`、`frontend/**`、`extension/**` 或共享 `contracts/**`。

当前唯一来源类型为 `MANUAL_EXCEL`。B 线未来可提交商品/SKU 线索或缺失知识上下文，但 C 线负责标准化、校验、去重与待审核管理，任何线索都不得自动成为正式知识。
