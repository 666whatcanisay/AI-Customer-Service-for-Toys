# 标准化规则

标准化是确定性的，不调用模型，也不补全事实：

1. 文本去首尾空白并把连续空白压成一个空格；空文本转 `null`。
2. `platform` 转小写，但未知值不会映射到已知平台。
3. 编码保留原始字符语义，仅执行通用空白清理。
4. 年龄只接受整数、整数值浮点或纯数字文本并转为整数；其他值保留给校验器报错。
5. 日期、日期时间统一为 `YYYY-MM-DD`；不可解析文本保留给校验器报错。
6. `specifications` 若为 JSON 对象/数组，按键排序并压缩为稳定 JSON；否则保留规范文本。
7. 完整规范化对象按稳定键序列化并生成 SHA-256 `row_hash`。
8. 身份键仅使用规范化的租户、平台、店铺、商品标识与 SKU 标识。

原始值与规范值分栏持久化，便于审核时追溯；不会用规范值覆盖原始证据。
