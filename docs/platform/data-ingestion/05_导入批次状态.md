# 导入批次状态

批次状态流为：

```text
RECEIVED → PARSING → VALIDATED → READY_FOR_REVIEW
                              ↘ REJECTED
RECEIVED/PARSING             → FAILED
```

- 文件扩展名、MIME 或大小在创建批次前校验；不合格请求不会产生批次。
- `READY_FOR_REVIEW` 仅表示至少一行进入 `StagedProductSku`，不表示审核、正式发布或可供客服回答。
- `REJECTED` 表示没有可暂存的有效行。
- 解析阶段的结构/行数/内部错误记录为 `FAILED`，响应仍返回稳定错误码。
- `review_status` 在 C-T02 中只有 `PENDING_REVIEW`，没有批准、发布或撤回转换。

不得从任何导入状态跳转到正式知识状态；C-T03 才能在独立授权后设计审核操作，C-T04 才能考虑向 A 线交付已审核、版本化知识包。
