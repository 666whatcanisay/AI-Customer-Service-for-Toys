# 校验与错误码

每条行级问题均包含 `error_code`、`message`、`row_number`、`field`、`raw_value`、`suggestion`。稳定错误码如下：

| 错误码 | 触发条件 |
|---|---|
| `REQUIRED_FIELD_MISSING` | 必填字段为空 |
| `INVALID_PLATFORM` | 平台不在允许值中 |
| `INVALID_INTEGER` | 年龄不是非负整数 |
| `INVALID_DATE` | 日期不是 ISO 日期 |
| `AGE_RANGE_INVALID` | 最小年龄大于最大年龄 |
| `EFFECTIVE_RANGE_INVALID` | 生效开始晚于结束 |
| `PRODUCT_IDENTIFIER_MISSING` | 两类商品标识均缺失 |
| `SKU_IDENTIFIER_MISSING` | 两类 SKU 标识均缺失 |
| `DUPLICATE_ROW` | 同批次完整规范化行重复 |
| `CONFLICT_REQUIRES_REVIEW` | 同一身份存在不同事实，或批次含多租户 |
| `UNSUPPORTED_FILE_TYPE` | 扩展名或 MIME 不允许 |
| `FILE_TOO_LARGE` | 上传或解压后内容超限 |
| `TOO_MANY_ROWS` | 数据行超过上限 |
| `INVALID_TEMPLATE` | 表结构、长度等模板约束不符 |
| `FORMULA_NOT_ALLOWED` | 数据单元格为公式 |
| `INTERNAL_PARSE_ERROR` | 解析发生未分类内部错误 |

优先级规则：基础字段无效的行保持 `INVALID`，不会被重复判定覆盖；完全重复的后续有效行标记 `DUPLICATE`；同身份的不同有效事实标记 `CONFLICT`；多租户批次最终全部标记 `CONFLICT`。只有最终 `VALID` 行进入待审核区，系统不自动合并冲突。
