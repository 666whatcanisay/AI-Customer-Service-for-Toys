# Excel 模板规范

正式模板为 `docs/platform/templates/商品与SKU资料模板.xlsx`。

- 工作表 `商品SKU资料`：第一行固定 18 个字段，第二行为说明，第三行起为数据；空白行忽略。
- 工作表 `填写说明`：填写、日期、标识、年龄和公式限制。
- 工作表 `允许值`：首批平台枚举及当前来源类型。
- 模板只含明确标注的人工虚构示例，不含真实公司、商品或客户数据。
- 日期格式为 `YYYY-MM-DD`，平台列和年龄列带输入约束。

服务端只把可见的 `商品SKU资料` 当作数据表；缺表、隐藏数据表、列名/顺序不符均返回 `INVALID_TEMPLATE`。第二行永不导入。只接受 MIME 为 OOXML workbook 的 `.xlsx`，不接受 `.xlsm`、CSV、压缩包、PDF、Word 或 OCR 输入。

模板通过 `@oai/artifact-tool` 创建，导出后重新导入检查了 `A1:R3`，公式错误扫描为 0，并逐张渲染目检三个工作表。
