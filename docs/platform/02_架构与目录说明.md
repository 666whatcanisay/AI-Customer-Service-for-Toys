# 架构与目录说明

本线只拥有：platform_backend/**、admin_web/**、docs/platform/**。跨线依赖使用共享契约，不复制或调用对方内部实现。

C-T02 后的主要目录：

- `platform_backend/app/ingestion/`：schema、model、service、repository、hash，以及 parser/normalizer/validator。
- `platform_backend/app/api/import_routes.py`：薄 HTTP 层，不包含 Excel 解析细节。
- `platform_backend/migrations/`：C 线自有数据的 Alembic 迁移。
- `platform_backend/tests/fixtures/`：纯人工构造 XLSX 测试件。
- `admin_web/src/views/Import*`：批次列表、新建导入、批次详情。
- `docs/platform/templates/`：正式固定模板。
- `docs/platform/data-ingestion/`：字段、规则、API、安全、测试和回滚基线。

数据流只到 C 线 `StagedProductSku(PENDING_REVIEW)`，不跨越到 A 线或正式知识区。
