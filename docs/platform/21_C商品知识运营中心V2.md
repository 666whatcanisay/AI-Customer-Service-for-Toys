# C 商品知识运营中心 V2

## 1. C 知识运营接入分析

### 可复用能力

- `TestStore/TestProduct/TestSku/TestFaq/TestSafetyRule/TestSourceEvidence` 已能提供店铺、商品、SKU、FAQ、安全规则和来源的 C 端业务投影。
- `KnowledgeMaterial` 已具备不可变修订、受控文件保存、幂等上传、人工审核和来源追溯能力。
- 商品知识中心 V1 已具备店铺 → 商品 → SKU 导航、知识主题覆盖度、缺失信息兜底和来源展示。
- 现有试点商品/SKU导入、反馈闭环和测试数据包继续作为兼容能力保留。

### V2 新增能力

- 六类中文运营模板的精确类型识别，只读取“数据填写”工作表，不把填写说明、字段说明或示例数据误当成真实知识。
- 上传范围由服务端按现有 C 目录核对店铺、商品和 SKU 关系；客户端不提交或控制租户字段。
- 商品投影同时展示资料状态与 AI 状态，避免把“上传成功”解释为“AI已可用”。
- 新增中文知识维护页，支持商品知识、SKU差异、FAQ和安全规则的结构化补充。
- 新增知识缺口中心，按缺失主题、出现次数、影响程度、优先级和处理阶段展示。
- 商品知识主路径不展示内部商品、SKU、租户、外部标识、内容校验或内部版本字段。

### 保持不变

- 不修改 Store/Product/SKU 底层模型，不创建 Master Data。
- 不修改 B 客服工作台、A RAG 核心、Prompt、模型训练或共享契约。
- 不自动发布知识；审核通过只形成 C 端受控资料，不代表已发布到 RAG。
- 不新增数据库表或 migration。

## 2. 状态规则

资料状态：

- `DRAFT`：现有结构化记录尚未审核，也没有待审核补充资料。
- `PENDING_REVIEW`：存在已接收、已识别或审核中的补充资料。
- `APPROVED`：现有结构化事实已审核，或存在已审核受控资料。

AI状态：

- `EFFECTIVE`：A级主题已由结构化、可追溯事实覆盖，且不存在高风险缺口。
- `PARTIALLY_AVAILABLE`：可以回答部分问题，但仍有缺口或仅有已审核资料提示。
- `MISSING_KNOWLEDGE`：缺少形成基础回答所需的知识。
- `UNCONFIRMED`：安全信息或安全来源不足，不能显示AI已就绪。

这些状态是 C 端“可回答依据”投影，不是 RAG 发布回执。

## 3. 页面

- `/knowledge-center`：店铺统计、商品业务事实、FAQ数量、资料状态、AI状态、主题覆盖和缺口。
- `/knowledge-center/products/{内部路由键}`：商品概览、SKU差异、FAQ、安全、来源、覆盖情况和补充建议。页面不展示内部路由键。
- `/knowledge-editor`：按中文业务名称补充商品知识、SKU差异、FAQ和安全规则。
- `/knowledge-gaps`：知识缺口列表与店铺、优先级、处理状态筛选。
- `/knowledge-materials`：六类模板上传、识别摘要、人工审核和受控修订。
- `/import-center`：六个正式中文 Excel 模板下载及兼容入口。
- 旧版 CSV 静态下载资产仅作历史链接兼容保留，不再作为 V2 运营填写入口。

## 4. C-only 接口变化

| 方法 | 路径 | 变化 |
| --- | --- | --- |
| GET | `/api/v1/admin/product-knowledge/gaps` | 新增知识缺口业务投影，可按店铺、优先级和处理状态筛选 |
| POST | `/api/v1/admin/knowledge-materials` | 兼容性新增 `template_type` 表单字段；未提供时沿用原受控资料上传 |
| GET | `/api/v1/admin/product-knowledge/overview` | 店铺摘要新增待审核数量 |
| GET | `/api/v1/admin/product-knowledge/products` | 商品摘要新增年龄、材质安全、包装、FAQ数量、资料状态和AI状态 |
| GET | `/api/v1/admin/product-knowledge/products/{内部路由键}` | 商品详情新增资料状态、AI状态、SKU差异字段、SKU FAQ数量和安全边界字段 |

以上均为 C-only Admin 增量；`contracts/**`、B/A路径和共享版本不变。

## 5. 六类模板接入

| 模板 | 受控资料类型 | 处理边界 |
| --- | --- | --- |
| 商品知识采集模板 | 商品规格 | 允许缺少非必填知识，但必须有业务范围、来源和确认状态 |
| SKU差异知识采集模板 | 商品规格 | 六类差异必须填写实际差异或“已确认无差异” |
| 客服FAQ知识采集模板 | 问答资料 | 标准回答必须有事实来源；高风险必须有来源 |
| 商品安全规则采集模板 | 安全说明 | 安全提醒、禁止承诺、转人工条件和来源必填 |
| 客服AI问题反馈模板 | 其他资料 | 必须确认已去除敏感信息；不进入 A 知识分析输入 |
| AI知识缺口管理模板 | 其他资料 | 用于 C 端运营闭环；不进入 A 知识分析输入 |

## 7. 已知边界

- Internal Pilot 管理端仍没有正式登录、RBAC、持久敏感访问审计和保留策略，不能宣称生产安全就绪。
- 原始资料仍要求运营上传前人工去标识化；当前只有提示性敏感标识拦截，不是完整自动脱敏。
- AI状态是 C 端可回答依据投影，不证明实时 RAG 已摄取或一定检索到相关事实。
- 真实试点数据的浏览器验收仍需在获准环境中执行。
