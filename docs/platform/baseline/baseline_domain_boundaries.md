# C 线领域边界

## 当前实现边界

C-T01 只证明 C 线服务与管理端可以独立安装、测试、启动和构建。`/health` 是 C 线内部骨架接口，不改变共享 `contracts/**`。

## 责任边界

- C 线拥有：平台业务事实、未来的知识生命周期、审核、发布编排、风险与审计设计。
- A 线拥有：检索、Embedding、模型与回答编排；C 线不得直连 Chroma 或改写 RAG 内部状态。
- B 线拥有：客服用户端与浏览器扩展；C 线不得修改其页面或扩展。
- 跨线交互必须先形成版本化契约，本轮没有跨线契约变化。

## 本轮禁止能力

商品/SKU、审核、风险规则、评测、权限、数据库、RAG 发布均未实现。计划书中的这些能力仍是后续任务，不能由当前骨架推断为已具备。
