# 安全与审计基线计划

## 本轮已有保护

- request_id 贯穿成功与错误响应，可作为后续审计关联键。
- 配置来自环境变量；仓库只提交 `.env.example`，不自动读取或提交 `.env`。
- 健康接口不返回密钥、客户数据、主机路径或业务统计。
- 管理端断网与服务错误分开呈现，不把失败显示为正常。

## 后续强制设计

- 原始区、脱敏区、治理区、试用区、正式区分离。
- 密钥不得进入 Git、数据库明文字段或日志。
- 客户完整信息不得进入普通日志；敏感查看与恢复操作必须记录操作者、原因、对象和结果。
- 发布、失效、恢复和配置变更必须形成不可静默删除的审计事件。
- 私有仓库不能代替加密、访问控制和脱敏。

## 当前未具备

本轮没有登录、权限、加密存储、敏感访问审计、备份恢复或生产安全验证，不能宣称这些能力完成。
