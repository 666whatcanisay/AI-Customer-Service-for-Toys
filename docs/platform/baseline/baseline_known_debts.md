# 已知技术债与限制

- 端口 8000 在本次验证时被其他本机进程占用；真实健康检查改用 8010。
- FastAPI/Starlette TestClient 发出 HTTPX 适配弃用警告，后续依赖升级时需处理。
- 后端依赖使用约束范围而非哈希锁文件；当前已验证版本记录在基线文档中。
- 管理端目前只有单一页面，没有全局状态管理、E2E 或浏览器自动化测试。
- 统一 500 响应已存在，但尚无生产级结构化日志和审计落库；为避免泄密，本轮不记录异常详情。
- 没有数据库、迁移、认证、授权、加密、审计持久化或备份恢复。
- 没有任何商品、SKU、知识、审核、风险、评测或 RAG 能力。
- `/health` 尚未进入共享契约；当前仅由同属 C 线的管理端消费。
- 根 `README.md` 仍描述仓库初始化时“没有可运行应用”的共同基线；因 C 线只拥有 `docs/platform/**`，本轮不越权修改根说明，需由主协调窗口统一更新。
