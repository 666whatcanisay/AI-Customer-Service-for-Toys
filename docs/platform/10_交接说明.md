# 交接说明

新 Agent 先阅读计划书、00、01 和 machine-context.json；只执行一张任务卡。完成后报告范围、未改内容、命令与结果、契约影响、风险、回滚和下一张建议卡。禁止修改：backend/**、frontend/**、extension/**。

C-T02 已建立可演示的商品/SKU XLSX 导入闭环；C-T02A 在其前面增加 `POST /api/v1/import-batches/product-sku/preflight`。管理端 `/imports/new` 必须先预检，只有 `can_import=true` 才开放正式上传。

关键不变量：有效行只能是 `PENDING_REVIEW`；错误或冲突不暂存；未审核数据不得发布到 A 线；不得接入金蝶或真实数据。共享 `contracts/**` 仍未修改。

预检没有数据库依赖，不应创建 `ImportBatch`、`ImportRow`、`StagedProductSku`，也不应要求先执行迁移；正式上传仍按 C-T02 使用数据库。后续 C-T02B 或 C-T03 必须另行授权，不得在交接时自动执行。
