# 商品知识运营中心 V1

## 1. 目标与边界

本模块面向 C 端运营人员，把现有试点商品目录和受控知识资料投影为“店铺 → 商品 → SKU → 知识内容”的业务视图，用于判断当前资料能支持 AI 回答什么、不能回答什么，以及下一步应补充什么。

它不是 Master Data、ERP、库存、订单或价格系统，不改变 Store/Product/SKU 底层模型，不发布知识到 RAG，不训练模型，不修改 Prompt，也不修改 B 客服工作台或 A RAG 核心。

## 2. 数据来源

投影只读取 C 已有数据：

- `TestStore`、`TestProduct`、`TestSku`
- `TestFaq`、`TestSafetyRule`、`TestSourceEvidence`
- 最新修订的 `KnowledgeMaterial`
- `KnowledgeQualityAssessment` 中状态为 `OPEN` 的缺口
- 待审核统计中的 `READY_FOR_REVIEW` 导入批次

未审核的 `RECEIVED/RECOGNIZED/REVIEWING` 资料只计入待审核，不提升知识覆盖。`APPROVED_FOR_ANALYSIS/ANALYZING/ANALYZED` 资料可作为部分资料证据，但仍不表示知识已发布到 RAG。

## 3. 覆盖规则

A级核心覆盖度包含九项：商品名称、SKU名称、商品介绍、核心卖点、适用年龄、材质与安全、包装内容、基础使用说明、常见问题。状态分为：

- `SUPPORTED`：存在结构化、可追溯的现有事实。
- `PARTIAL`：仅能提供基础识别，或只有已审核资料提示但没有完整结构化事实。
- `MISSING`：当前资料不能支持稳妥回答。

覆盖度按 A级九项计算，`SUPPORTED` 计 1，`PARTIAL` 计 0.5，四舍五入为整数百分比。B级零件数量、尺寸、拼装难度与时间、玩法、颜色款式、组合关系、SKU区别单独展示，不计入核心百分比。

“AI 可用商品”表示至少有商品名称，并具备 SKU 名称或基础商品介绍；它允许资料不完整，不表示已发布或实时 RAG 一定可用。页面始终显示边界说明。

## 4. 缺失资料处理

缺失字段不得自动补写。每个缺口返回运营建议和安全兜底，例如：

- 适用年龄：`当前资料未提供年龄信息，建议人工确认。`
- SKU区别：`当前资料未说明不同 SKU 的区别，建议人工确认后再回复。`
- 其他字段：明确说明当前资料未提供，并建议人工确认。

A 分析写回的开放缺口按现有 revision/hash 治理证据显示，不改变资料生命周期，也不会触发自动修复。

## 5. C Admin 页面

- `/knowledge-center`：真实统计、店铺选择、商品卡片、SKU 导航、覆盖度和缺口。
- `/knowledge-center/products/{product_id}`：商品概览、SKU 差异、FAQ、安全、来源、A级/B级覆盖、缺口、安全兜底和下一步补充动作。
- `/knowledge-materials`：通过中文业务名称选择店铺、商品和 SKU；上传、识别、人工审核与修订流程沿用冻结知识资料接口。
- `/import-center`：提供统一中文 Excel；旧版试点导入入口折叠保留。

技术标识、编码、hash 和 revision 只放在默认折叠的“技术详情”中；主操作路径不要求运营输入这些字段。

## 6. C-only API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/admin/product-knowledge/overview` | 读取真实统计、店铺知识摘要与边界说明 |
| GET | `/api/v1/admin/product-knowledge/products?store_code=` | 按店铺读取商品知识列表 |
| GET | `/api/v1/admin/product-knowledge/products/{product_id}` | 读取商品完整知识、覆盖和缺口 |

接口不接受 `tenant_id`，不返回 tenant 信息，不返回原始上传路径或原始资料正文，不执行写操作。既有 B/A 路径和 `contracts/**` 不变。

## 7. 中文模板

`admin_web/public/templates/AI客服商品知识资料模板.xlsx` 包含：

1. `填写说明`
2. `示例数据`
3. `字段说明`

模板使用商品名称、SKU名称、适用年龄、核心卖点、材质、包装内容、常见问题和安全提示等中文业务字段，不包含内部商品/SKU/租户技术字段。价格、库存、财务、采购和平台技术标识明确排除。
