# 已知问题与风险

- 不得把本地数据、密钥、模型、日志或客户信息带入共享仓库。
- C-T02 只是受控本地导入与待审核基线，不具备认证、权限、审计持久化、数据保留策略或生产安全能力。
- SQLite 仅为本地默认；跨批次去重、人工审核、正式发布和 PostgreSQL 验证未实现。
- 计划书旧 C-T02 与当前任务卡命名冲突；已记录差异并保持共享契约不变。
- 后端 TestClient 存在一条上游 HTTPX 适配弃用警告，不影响 40 项测试通过。
- C-T02A 预检只做格式和既有业务规则分析，不是防病毒、内容无害化或生产级恶意文件检测；不得据此宣称上传安全体系已完成。
- `can_import` 只控制管理端按钮；正式上传 API 为兼容既有调用保持独立可用，服务端仍会重复执行全部正式校验。
- C-T02B ZIP 校验包含路径、链接、加密项、条目数、展开体积、manifest/大小/SHA 和固定测试标志，但不是防病毒、内容无害化或生产文件安全认证。
- 测试目录没有认证、授权、审计持久化、保留/删除策略或并发重复导入恢复；只允许本地测试数据库。商品/FAQ 的 `publishable` 是源工作簿字段，不改变包级 `production_usable=false`，也不代表已正式发布。
- 五个 GET 已按任务内约定冻结并由 C 线测试验证；共享 contracts 和 A/B 消费端未改，因此不得宣称真实跨线联调通过。
- 详细清单见 `data-ingestion/09_已知问题.md`。
