# 已知问题与风险

- 不得把本地数据、密钥、模型、日志或客户信息带入共享仓库。
- C-T02 只是受控本地导入与待审核基线，不具备认证、权限、审计持久化、数据保留策略或生产安全能力。
- SQLite 仅为本地默认；跨批次去重、人工审核、正式发布和 PostgreSQL 验证未实现。
- 计划书旧 C-T02 与当前任务卡命名冲突；已记录差异并保持共享契约不变。
- 后端 TestClient 存在一条上游 HTTPX 适配弃用警告，不影响 29 项测试通过。
- C-T02A 预检只做格式和既有业务规则分析，不是防病毒、内容无害化或生产级恶意文件检测；不得据此宣称上传安全体系已完成。
- `can_import` 只控制管理端按钮；正式上传 API 为兼容既有调用保持独立可用，服务端仍会重复执行全部正式校验。
- 详细清单见 `data-ingestion/09_已知问题.md`。
