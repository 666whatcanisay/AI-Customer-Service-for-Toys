# AI 能力说明

## 能力定位

A 是本地 RAG/AI 能力层，通常在 `8000` 运行。它使用受控商品范围、已同步知识和本机 Ollama 模型，为客服生成可人工确认的建议；它不是客户自动回复机器人，也不是自动化业务执行器。

在运营中心 5174 中，AI 控制中心以只读业务化方式展示模型状态、知识状态、评测摘要、质量问题和最近分析。技术人员可展开查看模型版本、运行 SHA 和诊断信息，但这些信息不应干扰普通运营操作。

## 当前可用能力

| 能力 | 真实来源 | 人工边界 |
| --- | --- | --- |
| 商品范围内问答 | B 的商品/SKU 上下文 + C 受控资料 + A 检索/模型 | 客服确认、编辑、复制后自行发送 |
| 来源提示 | 检索命中文档/资料范围 | 不把来源提示当作完整事实或授权证明 |
| 模型与知识状态 | A `/api/status` 和控制中心概览 | 状态异常时不伪造成功回答 |
| 经验案例评测 | C 已批准的不可变快照 | 分析结果只提供建议，不修改 Prompt |
| AI 反馈分析 | C 已确认反馈快照与回写结果 | 只处理有 revision/hash 证据的记录 |
| 资料质量分析 | C 已批准分析的受控资料 | `ANALYZED` 不代表知识已发布 |

## 模型和运行限制

当前受控运行使用本机 Ollama 的 `qwen3.5:9b`。启动会检查模型可用性并执行真实聊天 smoke；模型未配置、服务不可用或知识不同步时，页面与接口应显示真实错误或未就绪状态，不能以 Mock 回答代替。

AI 默认不直接对客户可见，且不具备自动训练、自动改 Prompt、自动发布知识、自动发送客户消息、自动退款、自动售后、自动改订单或 ERP 写入能力。

评测、质量闭环与证据记录详见[AI 评测与质量闭环](evaluation-and-quality-loop.md)。架构关系见[系统架构](../architecture/README.md)。
