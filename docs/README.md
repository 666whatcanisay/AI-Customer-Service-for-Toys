## 永久安全边界

本项目当前禁止自动发送客户消息、自动退款、自动售后、自动修改订单、ERP 写入、自动训练、自动修改 Prompt 和自动发布知识。AI 只生成建议；业务操作必须由人工确认。任何资料、反馈或案例都应使用测试或已去标识化内容，且不得提交密钥、数据库、向量库、日志、模型或客户数据到 Git。
