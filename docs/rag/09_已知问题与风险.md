# 已知问题与风险

## AI 控制中心 V2 风险与边界（2026-07-27）

- V2 显示的是 A 进程和保存评测的快照，不是持久监控、生产 SLA、审计记录或员工评价数据；回答量/延迟会随进程重启重置。
- 保存评测的 19/28、来源覆盖和归因只说明该份 `live_c_api` 报告，不能外推为生产全量质量，也不授权自动修改 Prompt 或知识。
- Badcase 没有已批准的浏览器安全去标识聚合契约，因此四类计数必须保持 `null`；UI 不得推断或伪造数值。
- C feedback/效率来源仍可能未配置或未登记；V2 显示服务端受控状态和人工下一步，绝不自行请求未知 C 路径。
- 控制中心、运营概览或质量基线任一接口不可用时，对应区域会显示错误/暂无数据，不使用假数据。

## PILOT-HARDENING-A（2026-07-27）

- 诊断只解释已保存的 19/28 报告，不会新建或重放完整 C live evaluation。C 导出、服务和冻结版本不可用时，不能将诊断输出视为新的质量验证。
- `metadata_loss` 与 `key_facts` 是当前报告的直接信号，但仍需要 C/知识治理方核验导出、来源目录和期望事实；A 不得据此补造知识、篡改评测期望、重建正式向量库或自动调检索阈值。
- 当前没有 `retrieval_miss` 和 `model_expression_error` 直接信号，不证明检索/Prompt 永远没有问题；只表示该报告不支持把它们列为当前优先根因。
- 质量诊断 API 不返回原始评测问题、答案、事实、来源或内部文本。CASE 标识和计数仅用于受控技术复核，不能作为客户、员工或供应商评价数据。

## TARGET-PILOT-A（2026-07-27）

- `ai-operations.v1` 的回答量、延迟和错误分类是 A 进程内聚合，会在重启时清空；它不是持久监控、审计、生产 SLA 或员工评价数据。
- 当前质量/证据覆盖仅来自保存的 `a-t03-v031-live` 评测（19/28），其中 `source_ids` 通过 21/28。它揭示需要人工复核的评测/知识归属问题，但不授权自动修改 Prompt、规则或知识。
- Badcase 数量必须维持 `null`，直到 C 发布经过审核的去标识化 aggregate-only 读取契约。A 不得从原始反馈、模型分析文本、feedback 类型或页面行为反推统计。
- A 当前未配置 `PLATFORM_API_BASE_URL`，真实 C feedback 读/真实 qwen/写回/幂等循环尚无证据；效率摘要在 A 范围无登记契约。两项均为外部联调 BLOCKED，不应把 API 空态或 testclient 测试写成真实 C 成功。
