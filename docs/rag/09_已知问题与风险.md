# 已知问题与风险

- 真实闭环依赖本机已有 BGE 缓存、Chroma 依赖和 Ollama `qwen3.5:9b`；新环境缺少任一项会 ENV_BLOCKED。
- 本轮复用只读源项目的既有虚拟环境执行测试，没有在正式工作区安装依赖；正式 A 线仍需可复现的环境准备流程。
- 拒答主要依赖余弦距离阈值。当前正确/无关距离证据来自单份合成 PDF，阈值仍需更大评测集校准。
- 仅支持含文字层的 PDF，无 OCR、表格结构或复杂版式恢复。
- 当前索引构建接口为批量 upsert，尚无文档版本、删除、去重治理或并发写入策略。
- 启动阶段不会自动入库；空知识库/空 collection 时检索返回空结果并受控拒答。Embedding 缓存缺失会使 RAG 初始化失败，但健康接口仍可用于诊断。
- 测试有 13 个 httpx 兼容性弃用警告；不影响本轮测试，但依赖升级时需处理。
- 不得提交密钥、`.env`、真实知识、向量、日志、数据库、模型或客户数据。
- A-T02 仅达到合成数据 L1 本地验证，不是生产验收；Draft PR 尚待审查，不得执行 A-T03。
