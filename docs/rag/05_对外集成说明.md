# 对外集成说明

A 线只消费总控冻结的 C V0.3.1 rag-export 与 evaluations JSON，不访问 C 数据库或内部模块，也不修改 contracts。

设置 `PLATFORM_API_BASE_URL` 后，可从本机调用：

```text
POST /api/test-knowledge/sync/{package_id}
```

A 会先完整下载并验证包，再 upsert 到独立测试 Collection。tenant、平台、店铺、测试/生产标记、建议模式、自动发送和 total 任一不符都会拒绝。C 错误 `{error:{code,message,details?},request_id}` 不被当作成功数据。

本轮通过临时环境变量连接 `http://127.0.0.1:8012` 完成真实联调，未写入 `.env`。真实包可解析且双次同步幂等；真实 28 条评测仍为 0/28，因此接口可用不等于质量 Gate 通过。`backend/tests/fixtures` 与 fixture 报告仍只能用于开发回归。
