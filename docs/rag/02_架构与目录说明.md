# 架构与目录说明

A 线拥有 `backend/**` 和 `docs/rag/**`。A-T02 未修改其他线路或共享契约。

当前实际链路：

```text
API Client
  -> FastAPI app/main.py
  -> app/api/routes.py
  -> RAGService
     -> VectorStore
        -> BAAI/bge-small-zh-v1.5
        -> Chroma PersistentClient
     -> Ollama /api/chat (qwen3.5:9b)
  <- answer + action + sources + model + latency_ms + request_id
```

文档入库链路为 `DocumentLoader -> PyMuPDF 文本层 -> 标点优先重叠切分 -> BGE -> Chroma upsert`。Chunk ID 由文件名、页码、页内序号与正文的 SHA-256 稳定生成。

默认运行路径仍解析到 `backend/knowledge_base` 与 `backend/vector_db`，但 A-T02 测试只使用 pytest 临时目录，不创建或读取仓库内真实知识库和向量库。服务启动只打开既有 collection 并预热；不会自动扫描 PDF、下载模型或重建索引。Embedding 离线模式要求模型已在本地缓存。

当前只支持含文字层的 PDF；OCR、表格结构、多租户、文档生命周期、增量索引和 A-T03 能力不在本轮范围。
