# 架构与目录说明

A-T03 只修改 A 线 `backend/**` 与 `docs/rag/**`，消费总控冻结的任务内 V0.3.1 兼容约定，不修改共享 contracts 或 C 线实现。

```text
C GET /rag-export
  -> PlatformTestKnowledgeClient
  -> V0.3.1 strict validation
  -> TestKnowledgeIndex
  -> Chroma collection: test_knowledge_v031

POST /api/chat {question, context}
  -> exact tenant/platform/store/product filters
  -> exact SKU first; product-level fallback
  -> safety action arbitration
  -> Ollama only for DIRECT_ANSWER / CONTROLLED_ANSWER
  <- frozen data response + citations + echoed context
```

原 `documents` Collection 与 PDF 链路保持不变。测试知识使用独立 Collection；同步采用稳定内容 ID 与 upsert，重复同步不会增加记录，也不会清空或覆盖原索引。

范围查询固定为 `TENANT-PDD-SM-TEST / pdd / PDD-SM`。有 SKU 时先检索精确 SKU，再检索同商品的空 SKU 商品级知识；无 SKU 时只检索同商品的商品级知识。所有查询同时限制 `test_data_mode=true`、`production_usable=false`，其他商品、店铺或租户不能进入候选集。
