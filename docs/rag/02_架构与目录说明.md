# 架构与目录说明

A 线拥有 `backend/**` 和 `docs/rag/**`；本轮只修改 `docs/rag/**`。跨线依赖只通过共享契约，不复制或调用其他线路内部实现。

当前源码结构为：FastAPI `app/main.py` 挂载 `app/api/routes.py`，路由调用 `RAGService`，后者调用 `VectorStore` 和 DashScope OpenAI-compatible client；`DocumentLoader` 只读取普通文本 PDF。上述仅为静态源码事实，不代表服务、模型、Embedding 或 Chroma 已运行通过。

当前没有真实 PDF 或 `backend/vector_db`。计划中的分层服务、文档生命周期、多格式解析和安全回答策略仍是后续能力，不得写成现有能力。
