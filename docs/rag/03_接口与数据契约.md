# 接口与数据契约

共享契约版本仍为 `contracts/version.json 0.1.0`；A-T02 没有修改 contracts。本轮只固化现有 A 线 FastAPI 接口。

- `GET /api/health`：进程健康状态，RAG 未就绪时仍可返回 HTTP 200 和 `ready=false`。
- `GET /api/status`：返回 `ready`、初始化消息、模型配置状态和初始化错误。
- `POST /api/retrieval/search`：输入 `query`、可选 `top_k`；返回 `accepted`、阈值、最小距离与 `sources`，不调用 LLM。
- `POST /api/chat`：输入 `message`；返回 `answer`、`action`、`sources`、`model`、`latency_ms`、`request_id`。

每个 source 至少包含：`source_name`、`page`、`chunk_id`、`distance`、`excerpt`。低置信或无结果时 chat 返回 `action=REFUSE`、受控拒答文案和空 sources，不调用 LLM。

这些字段是 A 线本地接口的已测试事实，不代表计划中的跨线正式契约。任何跨线字段或版本变化仍须走契约评审。
