# 产品资产：定位、能力与路线

## 产品总览

AI-CS 是面向玩具客服场景的内部 AI 辅助平台。它把商品/SKU/FAQ/安全资料、客服问题、人工回复、运营审核和 AI 质量观察放在受控闭环中。产品目标是减少重复查询和整理工作，而不是替代客服或自动执行客户业务。

## 产品定位

| 角色 | 主要入口 | 可完成的任务 |
| --- | --- | --- |
| 客服 | B，`5173` | 选择店铺、商品和 SKU；提问；查看来源；复制并人工修改建议；提交案例或 AI 问题反馈。 |
| 运营 | C Admin，`5174` | 查看商品知识、导入资料、审核资料/案例、查看 AI 问题和质量结果。 |
| 技术负责人 | A 只读控制面 + C 的 AI 控制中心 | 查看模型、知识、运行状态、评测摘要和受控分析证据。 |
| 维护者 | Windows 脚本 | 受管启动、停止、状态、局域网诊断和防火墙检查。 |

## 能力地图

| 能力 | 当前状态 | 人工边界 |
| --- | --- | --- |
| 商品范围内 AI 客服建议 | 可用 | 客服确认、编辑、复制后自行发送。 |
| 商品目录、SKU、FAQ、安全规则 | 测试资料可用 | 运营核对来源，不把测试数据用于真实客户。 |
| 优秀案例与 AI 问题反馈 | 可用 | 提交不等于优秀；审核和分析均有人工环节。 |
| 客服经验/问题的 AI 分析 | 受控可用 | 只处理 C 已确认快照；不改 Prompt、知识或模型。 |
| 商品资料质量闭环 | 受控可用 | 上传、审核、分析结果均不等于 RAG 已发布。 |
| AI 控制中心 | 只读可用 | 展示真实运行投影；不提供模型切换或写入。 |
| ERP、售后、退款、自动消息 | 规划/禁止 | 当前没有执行入口。 |

## 产品边界

- 当前是内部测试/试运行能力，不宣称生产认证、审计、保留策略或完整自动脱敏。
- B 的身份是本地测试者标识，不是 SSO、正式登录或权限系统。
- C 的审核、A 的分析、B 的客服建议均不能绕过人工确认。
- 空数据、不可用服务和未实现模块必须如实显示，不能用虚构趋势、Mock 成功或零指标代替错误。

## 三个月路线（规划，不是已批准的自动化承诺）

1. **P0 客服效率**：观察 AI 使用、直接/编辑采用、未采用原因和处理时长；先冻结事件接口与隐私边界。
2. **P1 AI 质量**：基于人工确认的反馈和案例提高评测覆盖，运营审核优化建议；不自动改 Prompt。
3. **P2 ERP 只读镜像**：在冻结数据来源和权限后展示商品、SKU、库存和订单摘要；禁止 ERP 写入。
4. **P3 售后助手**：输出缺件、补发、图纸和物流的建议流程；不自动执行。
5. **P4 退款风险辅助**：提供证据摘要和人工复核提示；禁止自动退款。

进入任一规划项前，Control/Interface Owner 必须先冻结数据所有者、接口、状态、错误码、幂等与版本规则。
