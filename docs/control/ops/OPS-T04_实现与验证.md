# OPS-T04 实现与验证

## 交付范围

- Windows 中文批处理入口与 PowerShell 辅助脚本；
- 未跟踪本机配置模板；
- PID 与进程身份保护；
- 重复启动、重复停止、状态检查和失败回滚；
- 根 `.runtime/` Git 忽略规则。

未修改 `backend/**`、`frontend/**`、`platform_backend/**`、`admin_web/**`、`contracts/**` 或其他线路文档，也未启动任何后续 T04 功能。

## 进程安全模型

启动时记录直接服务进程的 PID、规范化可执行文件路径、UTC 启动时间和完整命令行 SHA-256。停止前重新读取实时身份，任一字段不一致即拒绝停止。端口仅用于可用性和状态提示，从不作为终止进程的依据。

未知端口占用、状态文件与实时进程身份不一致、核心健康检查超时均为阻塞条件。启动失败会按逆序停止本次新启动且身份仍匹配的进程，不触碰启动前已经存在的服务。

## 隐私与审计

`.runtime/` 隔离运行态配置、日志、SQLite、知识目录、向量目录和进程状态。审计记录不包含环境变量值、密钥、客户信息、问题或回答。该设计只验证本地进程保护，不声称具备生产审计、安全加固或权限隔离能力。

## 验证命令

开发阶段不占用 8000、5173、8011 或 11434。执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/tests/Test-OpsScripts.ps1
```

该测试覆盖固定端口、本机配置生成、当前测试进程的正向身份匹配、命令行哈希篡改拒绝以及三个中文入口存在性。完整启停与页面联调由三个 PR 合并后的最终 develop 集成 Gate 执行。
