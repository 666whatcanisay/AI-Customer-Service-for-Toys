# PILOT-HARDENING-V1：内部试运行运行手册

日期：2026-07-27

范围：仅 Windows OPS 编排、运行证据和控制文档。本手册不改变 A/B/C/Admin 业务代码、共享 contracts、依赖版本或客户数据模型。

## 运行边界

- C 仅监听 `127.0.0.1:8011`，A 仅监听 `127.0.0.1:8000`，客服电脑只访问 B 的 `http://<服务器私有IPv4>:5173/`。Admin 继续只监听 `127.0.0.1:5174`。
- 客服浏览器使用同源代理 `/rag-api` 与 `/platform-api`；禁止将 8000、8011 或 5174 交给客服电脑。
- 运行证据、服务日志与 SQLite 备份只放在被 Git 忽略的 `.runtime/`。它们可能包含运行或备份数据，禁止提交、发送到不受控位置或附到 PR。
- 自动化不会安装依赖、关闭防火墙、按端口强杀进程或改动网络配置。

## 每日启动流程

1. 确认服务器连接受控 `Private` 网络；运行 `检查AI客服防火墙.bat`。只有规则显示为 Private、TCP 5173、当前子网且已启用，才能让第二台客服电脑接入。
2. 计划性维护或恢复前，双击 `备份客服试运行数据.bat` 并输入 `BACKUP`。该工具使用 SQLite 在线备份 API；只输出文件名与元数据，不输出数据库内容。
3. 双击 `启动客服试运行.bat`。它按 C → A → B → Admin 启动并运行受管 PID、health、5173 页面与固定代理检查。
4. 双击 `检查客服试运行就绪状态.bat`。仅当结果为 `READY_FOR_CUSTOMER_PILOT` 时，才进入第二台电脑验收。
5. 在第二台受控客服电脑上运行仓库中的 `验证客服电脑访问.bat`，输入启动器输出的服务器私有 IPv4。必须同时通过 TCP、页面、`/rag-api/api/health` 和 `/platform-api/health`。

`FIREWALL_CONFIGURATION_REQUIRED`、`NETWORK_SEGMENTED` 或任何非 Ready 状态都不是可对客服开放的结论。

## 每日检查流程

1. 使用 `检查客服试运行就绪状态.bat` 查看 C/A/B/Admin 的受管记录、监听和 health。
2. 查看 `.runtime/pilot-ops-events/` 中的 JSONL 事件，只使用 `schemaVersion`、状态、探测布尔值和失败服务标签进行排障；不要将原始服务日志或备份内容贴入工单。
3. 如果使用者报告访问失败，在第二台电脑运行 `验证客服电脑访问.bat`。该检查不读取或保存客户输入、回答正文或响应内容。

## 故障恢复流程

1. 先运行状态检查与 `诊断AI客服局域网.bat`。未知监听者、PID 复用或身份不一致时，停止器会拒绝操作；不要手工按端口结束进程。
2. 一般恢复：双击 `恢复客服试运行.bat`，输入 `RESTART`。它按 Admin → B → A → C 的已验证 PID 记录安全停止，再按 C → A → B → Admin 恢复。
3. 维护窗口演练：双击 `演练客服试运行服务恢复.bat`，输入 `RECOVER`。它依次停止 A、C、B，并在每次后执行完整受管恢复。该操作会造成短暂服务中断。
4. 如果唯一问题是缺少 TCP 5173 Private 规则，恢复会报告“服务已恢复、试运行仍未就绪”。不得把这视为客户电脑可访问；具有管理员权限的操作者必须先使用现有 `配置AI客服防火墙.bat`，并确认它仅创建当前子网的 TCP 5173 规则。

## 状态与处置

| 状态 | 含义 | 允许的下一步 |
|---|---|---|
| `READY_FOR_CUSTOMER_PILOT` | 服务、同源代理、网络选择、Admin 回环及 5173 专用规则均通过 | 执行第二台电脑验收。 |
| `FIREWALL_CONFIGURATION_REQUIRED` | 服务可用，但没有合规的 5173 Private 子网规则 | 由管理员核验并显式配置规则；不开放其他端口。 |
| `SERVICE_NOT_READY` | 至少一个受管服务身份或 health 未通过 | 保留证据，使用安全恢复入口。 |
| `NETWORK_SEGMENTED` | TCP 5173 从客户电脑不可达 | 核对 Private 网络、当前子网规则和设备路由；不扩大暴露面。 |
| `CUSTOMER_PATH_UNAVAILABLE` | 5173 可达但页面或固定代理失败 | 检查 B 代理和 A/C health；不让客户电脑直连后端。 |
| `ADMIN_LOOPBACK_REQUIRED` | Admin 非回环或启用了 LAN 暴露 | 恢复 `127.0.0.1:5174`；不开放 Admin。 |

## 数据与审计

- 备份文件本身可能含业务数据。仅保留在服务器受控的 `.runtime/pilot-backups/`，并按独立的数据保留政策处理。
- `pilot-readiness`、`pilot-ops-events` 和备份元数据只保存状态、端口、URL、探测布尔值、文件名与大小；不保存客户内容、回答、令牌、密钥、本地配置或完整命令行。
- 当前 Gate 为 `CONDITIONAL PASS`：服务恢复与服务器侧探测已验证；受限于当前会话没有管理员权限，5173 专用规则及第二台电脑实际验收仍需完成。
