# BUG-A-004：已选择 SKU 时回答仍提示确认具体款式

- 等级：P2
- 模块：A AI 能力层 / 回答体验
- 状态：`OPEN_DEFERRED`
- 发现版本：`AI-CS@42bafcf6630ccbcd1c2dd1d55cb7d3fe735cb1e2`

## 问题描述

多 SKU 回归中，A 已准确绑定 Q65、Q66、Q66-RGB6，并只返回当前 SKU 来源，但个别回答仍包含“需要确认具体款式”的泛化提示。

## 复现步骤

1. 使用同一商品的三个明确 sku_id 分别提问颗粒数量。
2. 检查来源隔离正确，但观察回答措辞。

## 原因分析

安全生成策略倾向保留人工确认措辞，没有根据“调用方已明确提供 sku_id”收窄文字。

## 处理结论

这是 P2 体验问题，不影响来源隔离、事实正确性和安全边界。本冲刺禁止修改 Prompt，故不以结果后处理掩盖；后续 AI 质量任务在不削弱人工确认边界的前提下评估。

## 验证结果

当前 SKU 来源隔离、颗粒数和 `SUGGESTION_ONLY/AUTO_SEND_DISABLED` 均通过；措辞问题保留。
