# BUG-B-002 — B参考准备度与R006.1真实RAG引用状态不一致

- 等级：P2
- 模块：B 客服展示 / C知识资料状态 / R006.1商品知识发布
- 状态：OPEN_SCOPE_DEFERRED
- 发现时间：2026-07-31

## 问题描述

隔离浏览器验收中，商品已通过R006.1发布为`PUBLISHED`，A返回3个同商品chunks并生成正确、有引用的回答，但B“AI参考准备度”区域仍显示“暂无已审核资料”。

## 复现步骤

1. 在C Admin发布一个`APPROVED`商品的AI知识，确认3 chunks/3 embeddings。
2. 启用该商品客服使用。
3. 在B选择该商品并提问。
4. B准备度提示“暂无已审核资料”，但生成回答后展开依据可见3条`product-knowledge:{product_id}`引用。

## 原因分析

B准备度继续读取既有知识资料审核投影；R006.1发布的是C商品知识规范文档，两者是不同事实来源。A检索已经使用新发布chunks，因此这是状态展示一致性问题，不是检索或回答失败。

## 当前处理

本任务明确禁止修改B客服业务流程，未通过新增B判断或兜底越界修复。R006.1核心验收仍通过：商品可选、回答准确、引用正确、安全边界保留。

## 后续修复原则

后续应以正式接口契约统一“参考准备度”的事实来源，不能让B自行推断C/A状态，不能隐藏现有知识资料状态，也不能用静态文案覆盖真实RAG可见性。修复后需同时回归有资料、无资料、已发布、待重同步和同步失败场景。
