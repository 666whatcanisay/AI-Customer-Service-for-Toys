# BUG-B-003 — B 客服工作台残留测试环境文案

- 等级：P2
- 模块：B 客服工作台 / Production Finalization
- 状态：FIXED_VERIFIED
- 发现时间：2026-07-31

## 问题描述

AI-CS V1.0.0 浏览器正式化验收时，B 客服工作台左下角仍显示“测试工作台”和“不是正式登录系统”。该文案不影响商品目录、AI 回答或安全控制，但会让内部生产用户误判当前运行身份。

## 复现步骤

1. 启动标准 Runtime。
2. 打开 `http://192.168.1.11:5173/ai-chat`。
3. 查看左侧导航底部的运行边界说明。

## 原因分析

此前正式化扫描覆盖了页面主区域和运行横幅，但侧栏边界卡片沿用了早期静态文案。该问题是用户可见文案遗漏，不是 Runtime、权限、商品目录或 RAG 状态错误。

## 最小修复

- “测试工作台”改为“AI客服工作台”。
- 边界说明改为“AI 生成建议需人工确认；不自动发送、退款、补发或修改订单。”
- 不修改任何业务状态、接口、数据库、A 回答逻辑或 RAG 发布机制。

## 验证结果

- B 全量 Vitest：120 passed。
- B typecheck：通过。
- B production build：通过。
- Playwright 页面回归：旧文案不可见，人工确认、不自动发送、不自动退款和不修改订单边界仍可见。
