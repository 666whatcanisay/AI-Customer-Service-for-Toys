# 商品资料模板填写与提交说明

这四份模板用于让运营人员把已经核实的商品事实整理成可审核资料。它们不是数据库表，也不会在下载、填写或上传后自动发布到 AI。

## 先选哪份模板

| 你要整理的内容 | 使用模板 | 当前处理方式 |
| --- | --- | --- |
| 商品名称、年龄、安全提示、包装或玩法 | `商品资料模板.csv` | 可作为“资料上传与审核”的受控资料上传，随后人工审核。 |
| 单个颜色、款式、规格或组合关系 | `SKU资料模板.csv` | 可作为“资料上传与审核”的受控资料上传，随后人工审核。 |
| 客服反复遇到的问题和已核实回复要点 | `FAQ模板.csv` | 作为问答资料准备；不要把客户原话、聊天记录或订单内容复制进去。 |
| 安全提醒和禁止承诺 | `安全规则模板.csv` | 作为安全资料准备；必须由运营核对商品实物或官方说明。 |

当前“商品与 SKU”批量导入功能只接受该页面公布的专用导入格式。这里的四份 CSV 是面向小白的资料准备模板，不代表所有文件都可跳过审核直接写入商品库。

## 填写四步

1. 从运营中心“导入中心”下载相应模板，保留第一行标题。
2. 每一行只填写一个已核实事实；同一商品的不同 SKU 分行填写。
3. 在“事实来源说明”写明可供运营复核的来源类别，例如“商品官方说明书”或“已核实包装信息”。不要填写客户姓名、电话、地址、订单号、支付信息或内部密钥。
4. 在“资料上传与审核”上传文件，补全店铺、商品、资料类型和提交人，查看识别结果后由运营人工审核。

## 提交后的状态

`已识别，待审核` 表示系统只完成识别；请人工核对。

`已审核，待分析` 表示可由负责人显式发起资料质量分析；这仍不等于已发布到 AI 知识库。

`已完成分析` 表示 AI 已给出待补充项；请修改资料后创建新版本，旧版本与分析证据会保留。

## 不要填写

- 客户聊天全文、客户身份信息、电话、地址、订单号、支付信息；
- 没有核实的库存、价格、到货、赠品、退款或物流承诺；
- 完整 Prompt、模型密钥、系统路径或技术日志。

所有客服回复仍须人工确认。资料准备、审核和 AI 分析不会自动训练模型、修改 Prompt、发布知识、发送客户消息或执行订单动作。
