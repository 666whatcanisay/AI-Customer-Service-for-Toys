# 资料质量闭环验收清单（试运行）

本清单用于验收“运营上传资料 → 系统识别 → AI 发现缺口 → 运营修正 → 客服使用”。它不替代商品事实审核，也不授权自动发布知识。

## 准备

- [ ] 选用一份去标识化、可核对的商品资料。
- [ ] 已确定店铺、商品和可选 SKU 的真实范围。
- [ ] 文件、截图和原始资料不进入 Git、日志、向量库或客户界面。
- [ ] 运行环境为内部试运行，所有 AI 建议由人工确认。

## 运营中心（C）

- [ ] 上传返回资料标识、版本、内容哈希和中文识别摘要。
- [ ] 识别出的字段与实际资料一致；待补全字段没有被误报为已具备。
- [ ] 人工审核的状态依次为：已识别 → 审核中 → 允许 AI 分析。
- [ ] 审核后导出的仅是去标识化、不可变的版本快照。

## AI 分析（A）

- [ ] A 只读取“允许 AI 分析”的资料快照。
- [ ] 分析记录包含 `analysis_run_id`、模型版本、Prompt 版本、资料版本与内容哈希。
- [ ] AI 输出是中文资料质量摘要和可操作缺口，未保存思维链、完整 Prompt 或原始来源文件。
- [ ] 模型/平台不可用时显示失败，不生成伪造成功结果。

## 运营修正（C）

- [ ] 运营看到缺口的中文摘要、严重度和建议动作。
- [ ] 运营以原始商品事实修正资料，并创建新 revision，而不是覆盖旧版。
- [ ] 旧版的审核与分析记录仍可追溯。
- [ ] 没有自动发布到 RAG、自动改 Prompt、自动训练或业务执行动作。

## 客服使用（B）

- [ ] 商品/SKU 对应的资料状态只显示紧凑中文提示。
- [ ] 客服看不到原始资料、哈希、分析正文或技术错误。
- [ ] 资料状态异常不阻断现有选品、提问、AI 建议、复制、案例和反馈流程。
- [ ] 客服对答案和商品事实仍执行人工确认。
