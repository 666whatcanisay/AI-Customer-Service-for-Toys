## 4. 客服端真实使用验证

在 B `15173` 使用测试身份和真实目录数据完成：

1. 选择“拼多多 → 汕明（测试数据）”；商品下拉显示 C 返回的全部 5 个商品。
2. 选择“8合1突袭装甲坦克（雪战/陆战款）”和“陆战沙色坦克”。
3. 页面展示真实的“AI 参考准备度”提示，资料存在待补充项时仍允许提问，但明确要求人工核对，不将状态伪装成“已准备完成”。
4. 输入测试问题“这个款式适合几岁的小朋友？安全注意事项有哪些？”，得到真实建议回复：适用 `6～12岁`、含小颗粒、不适合 3 岁以下儿童、建议成人陪同。页面显示 6 条回答依据、可编辑回复与人工复制入口。
5. 页面明确显示 `SUGGESTION_ONLY；AUTO_SEND_DISABLED`；没有自动发送、退款、订单修改、售后、Prompt 修改、模型训练或知识发布。

此前观察到的“店铺已选中但商品为空”未在最新候选页面复现。经复核，C 响应字段与 B 适配器一致，CORS 对 `15173` 已许可，原因是旧页面/旧启动实例，不是跨线接口漂移；未为此新增接口或业务代码。
