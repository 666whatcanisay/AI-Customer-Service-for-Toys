# AI-CS ChannelAgent 1.5.0 新客服电脑验收手册

## 使用边界

这份手册用于一台新 Windows 客服电脑。真实 PDD 登录必须由客服本人扫码；系统不保存密码、Cookie 或明文 Token，不自动回复。

## 主机端一次启动

1. 确认 AI-CS 与 Channel Engine 位于同一主机，并连接“专用/私人”局域网。
2. 右键 `scripts/windows/启动局域网AI客服主机.bat`，选择“以管理员身份运行”。
3. 看到主机名称、局域网地址和 12 位一次性连接码。
4. 连接码 5 分钟失效且只可用一次；不要通过群聊长期保存。
5. 用 `scripts/windows/检查局域网客服主机.bat` 查看服务状态。

## 客服端首次安装

1. 解压 `AI-CS-Channel-Agent-1.5.0-windows-x64.zip`。
2. 双击 `安装AI-CS客服端.bat`。
3. 首次向导点击“搜索局域网主机”。
4. 核对主机名称与地址，输入主机屏幕显示的连接码。
5. 勾选人工确认，再执行绑定；发现主机不会自动绑定。
6. 管理员在服务端授权用户和一个或多个店铺。
7. 客服端从授权集合选择一个当前工作店铺；同一时刻只能有一个 `active_store_id`。
8. 首次 PDD 登录由客服人工扫码，页面识别店铺必须与当前工作店铺一致。
9. 进入桌面助手，完成一次消息接收和 AI 建议生成；真实发送仍需人工确认。

## 自动化验收替代流程

无人值守回归不能登录真实 PDD。使用 Synthetic PDD 验证同形契约：

`模拟买家消息 → Agent → CustomerContext → AI-CS → 桌面助手 → 仿真发送 → Receipt`

只有 SIMULATOR 模式允许测试自动确认，生产配置始终保持人工审批、自动回复关闭、真实发送关闭。

## 后续开机

Windows 开机后 Agent 自动驻留托盘，恢复设备凭证引用、授权店铺集合、唯一活动店铺和独立 Edge Profile。若 Session 有效则恢复工作环境；失效时明确要求人工扫码。

## 故障停止

- 客服端：托盘菜单选择“安全停止并退出”。
- 主机端：运行 `scripts/windows/停止局域网AI客服主机.bat`。
- 停止不会删除设备绑定、审计、Receipt 或浏览器 Profile。
