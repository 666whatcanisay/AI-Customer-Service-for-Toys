# 运营中心使用手册

## 入口与定位

C 运营中心通常运行在 `http://127.0.0.1:5174/`。它负责保存和展示受控业务资料、客服经验、AI 问题与分析结果；它不是 ERP，也不会自动执行客户业务动作。

运营首页应优先显示真实业务摘要、待处理事项和服务状态。空数据、服务错误或未实现模块必须如实显示，不能用虚构趋势或“0”替代报错。

## 日常工作顺序

1. 在“商品知识中心”确认店铺、商品、SKU、FAQ 与安全资料是否对应、可追溯且可供审核。
2. 在“导入中心”下载并填写受支持的模板，先预检，再执行导入；有失败项时下载错误报告并修正后重试。
3. 在“客服运营”审核经验案例：`NEW → REVIEWING → APPROVED`，或由 `NEW → REJECTED`。已通过案例形成不可覆盖的版本快照，后续修改需要新 revision。
4. 在“AI 问题”查看真实反馈，关注 `NEW → ANALYZING → ANALYZED` 的处理状态。
5. 在“AI 控制中心”查看模型、知识、评测和分析的只读投影；分析建议仍需人工判断，不能直接发布知识或修改 Prompt。

## 资料质量生命周期

受控资料的典型生命周期为：

`RECEIVED → RECOGNIZED → REVIEWING → APPROVED_FOR_ANALYSIS → ANALYZING → ANALYZED`

也可在审核或处理环节被拒绝、失败。`ANALYZED` 表示已有受控分析结果，不表示已自动写入 RAG、自动发布或可直接对客户使用。

## 运营红线

- 不上传真实客户身份信息、密钥或未授权的原始数据。
- 不将测试数据当作生产结论；商品年龄、警示、库存、物流等关键事实必须回到来源资料核对。
- 不把 AI 分析或质量建议当成自动决策。
- 不进行 ERP 写入、自动退款、自动售后或自动发送。

资料规范和模板说明见[数据资产说明](../data/README.md)与[模板和导入说明](../data/templates-and-import.md)。
