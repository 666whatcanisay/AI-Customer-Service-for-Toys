# 客服工作台使用手册

## 适用范围

本手册面向使用 B 客服工作台（通常为 `http://127.0.0.1:5173/`）的内部客服。当前数据和模型能力仅用于测试或受控试运行；任何对客户的发送、承诺、退款或订单处理，都必须由人工在本系统外确认并执行。

当前工作台使用本地测试身份标识保存操作来源。它不是公司 SSO、密码登录或完整权限系统；不要把它当成正式身份认证。

## 一次咨询的推荐流程

1. 进入“AI 客服”，确认当前测试身份与店铺上下文。
2. 依次选择店铺、商品；已知具体款式时再选择 SKU。不要用一个商品的资料回答另一个商品的问题。
3. 输入客户的原始问题。不要输入手机号、详细地址、身份证号或真实订单号。
4. 查看 AI 建议、适用范围和来源提示。状态为“建议人工处理”或资料不完整时，不要把建议直接作为结论。
5. 复制建议后，在实际客服渠道人工编辑、核对并发送。本平台不会自动发送任何客户消息。

## 经验案例与 AI 问题反馈

当一条人工最终回复具有可复用价值时，可保存为客服经验案例；提交后只是 `NEW`，不代表已被认定为优秀。运营审核后才可能进入受控的 AI 评测范围。

当 AI 回答没有被采用时，提交 AI 问题反馈，并选择最接近的原因：

| 类型 | 说明 |
| --- | --- |
| `FACT_ERROR` | 事实错误 |
| `MISSING_INFO` | 缺少必要信息 |
| `STYLE_ISSUE` | 表达、语气或结构不合适 |
| `RISK_ISSUE` | 有安全、合规或错误承诺风险 |
| `OTHER` | 其他、需补充说明的原因 |

提交前应去标识化；普通聊天不自动进入优化池。反馈只用于人工审核和受控分析，不会自动修改 Prompt、知识或模型。

## 常见提示

- “无商品 / 无 SKU”：先回到商品选择步骤，确认数据包已经导入并选择了正确店铺。
- “AI 不可用”：保留问题，不要编造回答；稍后重试或联系维护者检查服务状态。
- “资料不足”：向运营提交资料补充需求，不能以猜测补全参数、年龄、安全结论或库存信息。
- “来源不匹配”：不要复制该建议，重新选择商品/SKU 或提交反馈。

维护者的启动、状态和故障处理请看[故障排查手册](troubleshooting.md)。
