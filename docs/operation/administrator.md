# 管理员与技术负责人手册

## 管理目标

管理员使用 5174 的运营中心管理受控资料、审核队列、系统状态和只读 AI 能力投影。技术详情默认应折叠：运营用户先看中文业务摘要，需要排障时再查看 SHA、模型版本、进程与请求细节。

## 关键页面

| 页面 | 管理目的 | 边界 |
| --- | --- | --- |
| 运营概览 | 查看真实数据摘要、待处理事项和服务提示 | 不用虚构趋势填补空数据 |
| 商品知识中心 / 导入中心 | 管理受控商品资料与导入结果 | 导入前预检，失败后按错误报告修正 |
| 客服经验库 / AI 问题 | 审核沉淀案例，查看可追溯反馈 | 不能把提交直接当作优秀或事实正确 |
| AI 控制中心 | 阅读模型、知识、质量、评测和问题分析状态 | 只读，不提供自动训练、Prompt 修改或知识发布 |
| 服务状态 | 查看 C/A/B/Admin 的健康与受管运行信息 | 停止服务必须使用受管脚本，不能按端口强杀 |
| 知识来源 | 核对元数据、校验值和范围 | 该页不负责预览、下载、发布或编辑来源文件 |

## 访问与权限现状

当前是内部测试/试运行环境，不应对外网开放。B 使用本地测试身份标识；完整账户、SSO 和复杂 RBAC 不在当前范围。管理员必须用环境隔离、受管入口和人工流程补足这一限制，不能把未实现的权限能力写成已具备。

## 运行与审计提示

受管运行记录会同时保存服务进程和实际监听进程的信息。状态脚本会区分 `RUNNING` 与 `LISTENING`，并通过 PID、启动时间、路径、命令特征和健康检查验证身份。未知进程、未知端口占用或不匹配记录不得被脚本或人工“顺手结束”。

完整的启动与故障处理请转到[故障排查手册](troubleshooting.md)。
