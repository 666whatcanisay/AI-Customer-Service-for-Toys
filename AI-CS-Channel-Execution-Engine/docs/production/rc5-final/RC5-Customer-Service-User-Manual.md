# RC5 客服使用手册

## 正常状态

顶部应显示 Agent 在线、当前店铺和 `REAL SEND = OFF`。离线/Pilot 初期模式应为 `MANUAL_CONFIRM`。

## 处理一条会话

1. 在左侧会话列表选择客户。
2. 核对客户消息、店铺、商品和 SKU。
3. 等待 AI 草稿生成。
4. 查看风险、质量状态、知识依据和警告。
5. 内容不正确可修改、拒绝或标记问题。
6. 内容可用时点击“人工确认并准备执行（不发送）”。
7. 正确结果应为“执行已准备，尚未发送真实 PDD 消息”。

## 必须转人工

- 退款、赔偿、投诉、法律承诺或高风险问题。
- 缺少知识依据、Quality Gate BLOCKED、置信度不足。
- 商品/SKU/订单上下文不一致。
- 任何店铺或客户身份疑似串线。

## 禁止误解

`EXECUTION_PREPARED` 只代表通过人工确认并生成执行准备，不代表已经发送，也不代表存在真实 Receipt。
