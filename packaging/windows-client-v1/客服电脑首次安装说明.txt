AI-CS 客服端 2.0.0rc2（客服电脑）

第一次使用：
1. 双击“安装AI-CS客服端.bat”。安装完成后会自动启动，无需在解压目录里再次运行 ChannelAgent.exe。
2. 安装器会在桌面创建“AI-CS 客服助手”快捷方式；程序启动后常驻 Windows 托盘。
3. 客服端会打开“连接 AI-CS 客服主机”向导。
4. 点击“搜索局域网主机”，核对主机名称、证书指纹和地址。
5. 输入主机屏幕显示的一次性连接码。
6. 勾选人工确认后点击“确认绑定”。系统不会在发现主机后自动绑定。
7. 管理员完成用户与店铺授权后，在客服端选择当前工作店铺；同一时间只能运行一个店铺。
8. 首次 PDD 使用由客服人工扫码。系统不保存密码、Cookie 或明文 Token。

以后使用：
- Windows 开机后客服端自动驻留托盘，并恢复独立 Edge Profile。
- 双击托盘图标打开客服助手。
- 关闭客服助手窗口只会隐藏窗口，不会退出 Agent 或主动关闭 PDD。
- 需要退出时，右键托盘图标选择“安全停止并退出”。

安全规则：
- AI 回复必须人工确认；自动回复和真实发送默认关闭。
- UNKNOWN 结果不会自动重试，必须人工核对。
- 切换店铺前必须清空待审核、执行中和 UNKNOWN 任务。
- 生产主机只提供 Agent Control 2.1；旧 V1 客户端必须重新可信配对。
