# Knowledge lifecycle governor

1. Enforce the approved knowledge state machine and reject illegal transitions.
2. Refuse formal publication for unreviewed, unsourced, expired, or unconfirmed high-risk knowledge.
3. Report a failed RAG publication as failed.
4. Keep every version transition traceable.

Never auto-promote an excellent case into formal knowledge.
